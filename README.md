# FoodOrder — Online Food Ordering and Restaurant Discovery Website
A mobile-first responsive webpage for exploring restaurants, food categories and menus using CSS Grid and Flexbox.
## Technologies
- HTML5
- CSS3
- CSS Grid
- CSS Flexbox
- Media Queries
- Container Queries
- Git
- GitHub
## Features
- Responsive header and navigation using Flexbox
- Restaurant listing using CSS Grid
- Six restaurant cards
- Mobile-first responsive design
- Media queries for tablet and desktop
- Container query for restaurant cards
- Hover effects on restaurant cards
- Cross-device testing documentation
## How to run
Open `labexpt3.html` in a web browser.
